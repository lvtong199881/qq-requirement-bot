# 群里的指令

> 返回 [README](../README.md)

bot 只处理**群消息**，私聊不响应。

## 斜杠指令

| 指令 | 谁能用 | 作用 |
| --- | --- | --- |
| `/help` | 已授权成员 | 回一段用法说明 |
| `/stop` | 已授权成员 | 打断当前正在跑的回合 |
| `/release` | **群主 / 白名单 / superAdmin** | 释放当前会话与进程 |

**权限模型**：能驱动 bot 的只有三类人，其他成员 @ 它会被**静默忽略**——不回任何话，
连「你没权限」都不说（避免刷屏和误触发）。

| 身份 | 生效范围 | 从哪来 |
| --- | --- | --- |
| `superAdmin` | 任意群 | `bot.config.json`，面板不允许改 |
| 群主 / 群管理员 | 仅本群 | OneBot `get_group_member_info` 判定，按群缓存 5 分钟 |
| `adminUsers` 白名单 | 任意群 | 面板或配置文件，额外放行 |

这里的「任意群」只是突破**人**的限制，不突破**群**的限制：群本身若被
`excludeGroups` 排除、或落在 `groupPolicy.mode=deny` 下，superAdmin 也照样不服务。

`/release` 比「能驱动 bot」再严一档：**群管理员也不能执行**，只认群主、`adminUsers`
和 `superAdmin`。

## 说人话

| 说法 | 行为 |
| --- | --- |
| `通过` / `好的` / `可以` / `同意` / `ok` / `lgtm` | 放行当前阶段，进入下一阶段 |
| `打回` / `不行` / `不对` / `有问题` / `重做` | 退回当前阶段重做 |
| `继续` / `接着跑` | 上一轮异常中断时，从当前阶段接着跑 |
| 其他任何内容 | 当作对当前等待事项的回答 |

流程由状态机驱动，所以 bot 永远知道自己在等什么：等澄清回答、等阶段确认、等合并确认。
你回什么，它按当前状态解释，不需要记指令。

## 群消息有哪几种

1. **阶段开始**：`当前「设计」阶段中。`
2. **阶段完成 + 产物**：`设计阶段已完成。` + `产物：设计说明.md`
3. **等你确认**：把 agent 提出的疑点渲染成 A/B/C 选项，或一句「回复通过/打回」
4. **异常**：`阶段异常，请联系 bot 管理员，异常原因如下：…`
5. **完成**：`「<需求名称>」全部完成。`

agent 的工作过程不进群——过程文字只留在它自己的会话里，群里只看到这三类状态和产物。

## 一个群一个需求

做完也占着这个群。要开新需求就换一个群，或者先 `rm .state/group-<群号>.json` 清掉绑定
（产物还在 `docs/requirements/` 里，不会丢）。
